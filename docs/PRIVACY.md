# 数据与隐私

## 数据放在哪里

默认在手机应用私有目录保存 Room 数据库、设置和回执 JPEG。公共构建没有私人 NAS 地址或令牌，默认不启用同步。启用自托管同步后，交易、人物、资产、商户规则等进入自己管理的服务器；回执图片也会传到该服务器。选用 WebDAV 时，账本进入使用者填写的服务。

本项目没有远程 AI 记账接口，没有接入广告平台或项目自建分析平台。OCR 使用随应用引入的 ML Kit 文字识别库，业务代码在本机处理图片。此描述来自代码路径审查，不等于对操作系统或所有第三方库网络行为的流量认证。

## 权限不是装饰

- 无障碍可能读取支持应用的页面文字；通知读取可能接触支付及消息内容。解析有应用和页面门禁，但无法将系统授予的权限范围缩小成“只会看到金额”。
- 本机截图识别需要使用者显式开启，受系统版本、支付保护及页面安全标记影响。未拿到截图时不能承诺识别。
- 识别完成仍应核对金额、商户、方向、资金账户和是否重复。自动提交默认关闭。
- 调试采集默认关闭；打开后，节点、原始文字等可能保留在本机调试记录中。分享日志前仍需脱敏。
- 截图可能含账户尾号、姓名、时间或订单号。确认并附入账单后，它就是账本的私人数据；分享或公开前需单独检查。

## 当前保护与局限

已有应用私有目录、Android `allowBackup=false`、同步令牌校验、系统证书验证、公共地址 HTTPS 约束、请求与附件大小/哈希校验、默认离线和演示版本隔离。公开版不自动将自定义同步令牌带到重定向地址。

**尚未提供端到端加密、加密 Room 数据库或完善的密钥库凭据存储。** 同步凭据存储于应用私有 SharedPreferences；可选编译默认值可以从 APK 提取。设备 root、系统备份权限、NAS 管理员或备份访问者可能读取数据。不要把带真实编译配置的 APK 当成公开演示包分发。

服务器使用家庭共享令牌，而不是每位成员独立鉴权。两位使用者具有平等编辑权限，持有同一令牌的人处于同一信任边界。LWW 同步、文件备份和哈希并不代替访问控制或完整灾难恢复演练。

删除账单产生墓碑；服务器保留追加日志，备份和附件也可能继续存在。当前没有“一键抹去全部历史副本”的保证。彻底清除需要同时处理手机、NAS 数据、日志、附件和备份，并防止旧设备再次同步。

## 私人配置

- Android：复制 `config.local.properties.example` 为 `config.local.properties`。这是可选的编译默认值；不提交真实身份、家庭标识、地址或令牌。
- 服务端：复制 `.env.example` 为 `.env.local`，自行生成随机口令。示例占位符不能运行服务。
- 签名：私钥和 properties 留在仓库之外，通过 `FL_SIGNING_PROPERTIES` 显式提供。不要更换现用私人安装签名或拿公开包覆盖现用数据。
- `.gitignore` 只是防误提交辅助，不能清理已经进入 Git 的内容。提交前应运行仓库扫描和完整历史扫描。

如果凭据曾公开，应撤销/轮换；仅删除文件不代表远端缓存、fork 或已有副本消失。处理步骤参考 [GitHub 官方说明](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository)。本次未创建远端仓库、未 push，不把“曾在本地出现”直接当作“已公开泄漏”。

## 公开材料规则

本仓库不得出现真实账本、私人截图、原始聊天记录、NAS 访问配置、签名文件、SSH 私钥、设备标识与本机个人路径。演示使用明确虚构的人物与账户。安全报告只记录类别、相对位置和处理结果；详细私人扫描证据留在公开目录之外。

发现可能泄漏时，请不要把秘密贴进公开 Issue。先停止分享该材料，在作者提供的私密渠道中联系；当前不编造不存在的安全邮箱。
