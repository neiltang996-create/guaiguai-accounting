# 公开截图来源与隐私检查

2026-09-27 在隔离 Android 35 模拟器中运行 `PublicScreenshotsTest` 生成六张 PNG。测试调用本项目生产 Compose 页面，账本使用内存 Room 和 `DemoData`；没有读取私人手机、NAS、历史 CSV、通知或支付截图。

- `home.png`：当月虚构支出 178 元、收入 6,000 元；家庭净资产 12,672 元。
- `assets.png`：四个虚构共享账户，名称均含“示例”；没有真实账户尾号。
- `roles.png`：记账人、付款人和消费人的独立选择。
- `recoveries.png`：上月虚构支出 100 元，本月退回 20 元、报销 30 元，原单净支出 50 元。
- `stats-income.png`：收入分析及月份/年份/自选日期入口。回溯退款属于原支出月，所以当前月的退款统计为 0。
- `auto-confirm.png`：手工注入“示例社区便利店、30.50 元”的合成信号，不是对真实支付宝的截屏或识别效果承诺。
- `overview.jpg`：首页介绍图，排版使用 `home.png`、`roles.png`；未生成或重绘应用界面。

六张 PNG 为 1080 × 2400，介绍图为 1440 × 810。状态栏时间来自模拟器截取时刻，不是私人付款时间。逐张检查可见文字、账户、金额、通知、背景；PNG 仅含 IHDR / sRGB / sBIT / IDAT / IEND，不含文字元数据或 EXIF。JPEG 仅保留普通 JFIF 与 ICC 色彩配置标记，不包含 EXIF、GPS 或作者路径。

图片 SHA-256 见 `SHA256SUMS`。重做图片后，必须再次人工查看并更新校验值。扫描器跳过图片像素内容，不能用“零命中”代替这一步。
