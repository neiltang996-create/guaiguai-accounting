# Roadmap

这是方向清单，不是发布时间承诺。

## WIP：先把日常功能做稳

- 自动识别：继续验证微信受限页面、银行明细、商户提取与返回账单后的稳定性；保持总览不弹、重复不重复入账。
- 两端同步：覆盖更多并发编辑、弱网和恢复场景，改进 LWW 冲突可见性。
- 附件：完善截图预览、删除后的清理与备份恢复行为，降低保存无关页面内容的风险。
- 配置体验：把个人私用的编译默认值继续转为清楚的首次设置；避免误开未配置的同步。
- 文档与测试：新增兼容案例时只提交合成样本，保留可重复的 Demo 截图流程。

## Experimental：需要更多验证

- Android 厂商后台限制、支付保护和系统版本差异。
- 本机 OCR 对金额、商户、时间与账户的置信度和回退交互。
- WebDAV 的服务兼容性与附件同步体验。

## Planning：尚未完整交付

- 预算、日历和周期账单用户流程。
- 通用 Excel 导入与更灵活的导入映射。
- 端到端加密、系统密钥库和本地数据库加密方案评估。
- 更完整的恢复演练、数据清除与可审计同步冲突处理。
- 无需重新编译的双人显示名与特殊商户规则管理。

## 暂不追求

不以多家庭 SaaS、企业财务、报税或投资建议为目标。不为了展示效果宣称自动识别完全准确，也不将个人实测等同于所有机型兼容。
